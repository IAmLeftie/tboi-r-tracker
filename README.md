# TBOI: Repentance Tracker
A companion application to The Binding of Isaac: Repentance which provides contextual random suggestions for what to do next in your save file!

# How to use
Open the application, select a save file, and hit Start. You will be brought to a main menu where you can set up unlocked characters, completed marks, unlocked bosses, challenges, and other miscellaneous progression markers. When you're ready, hit "LET"S ROLL!", configure the randomizer settings, and click the D6!

# Installation
Download the latest release, extract, and then run the EXE and enjoy!

# Contributing
TBOI:R Tracker is a Godot 4.6.2 application, so any installation of a Godot version compatible with 4.6.2 project files will be able to open the project directly!
